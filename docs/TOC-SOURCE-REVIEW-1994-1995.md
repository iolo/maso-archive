# 1994–1995 TOC source corrections

The owner's requested source review corrects 46 transcription details in 45
entries, consistently in `TOC-1994.md`, `TOC-1995.md`, and the merged `TOC.md`.
All 1,811 added entries retain their order and indentation. The earlier source
through December 1993 is unchanged. This is a targeted suspicious-text review,
not a complete reconciliation of missing entries, hierarchy, or supplements.

The [correction log](../data/overrides/toc-source-review-1994-1995-2026-11-04.json)
records exact previous and corrected lines, issue dates, source locations,
before/after file hashes, evidence paths and hashes, and reasons. It is source
review evidence, not an importer identity-decision file. Private scan/CD files
remain in their existing locations and are not copied into version control.

All 53 donated images for these years were visually inspected: 52 TOC pages and
one July 1995 advertisement. The July donation contains only one TOC page, so its
remaining entries cannot all be checked against these scans. Existing OCR helped
locate text; direct visual reading determined scan corrections. Restored CD2/CD3
article text corroborates selected readings. Similarity matches alone never
authorize a correction.

The log also records deliberately retained printed readings, including February
1994's repeated DLL installment `(1)`, May 1995's `핸드 오피스`, October 1995's
`리즈툴즈`, and December 1995's page 580. A CD title can differ legitimately from
the printed TOC: September's scan reads `The Way Thing Work`, while CD3 reads
`The Way Things Work`. The transcription follows the scan.

At source-review closeout, the merged source contained 146 issues and 7,110
entries. An isolated import with a temporary registry validated that source;
the versioned registry, catalog pins, historical reviews, restored articles,
original images and reader outputs remained unchanged. The subsequently
authorized November 4 catalog migration is recorded in
[TOC import](TOC-IMPORT.md#1994–1995-source-merge). It preserves every previous
identity and historical restoration package. Reader delivery remains separate.
